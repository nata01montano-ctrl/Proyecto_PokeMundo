# PokéMundo

## Descripción del proyecto

PokéMundo es una aplicación móvil desarrollada en Flutter que combina el universo Pokémon con diferentes contenidos interactivos. Su objetivo es ofrecer a los usuarios una experiencia sencilla y entretenida mediante la consulta de Pokémon, productos y recetas de cocina.

## Objetivo

Desarrollar una aplicación móvil que integre diferentes API REST para consultar y presentar información de manera dinámica, utilizando Flutter y el lenguaje Dart.

## Funcionalidades principales

- Pokédex: permite visualizar y buscar Pokémon.
- Favoritos: permite marcar Pokémon como favoritos.
- Detalle del Pokémon: muestra información como nombre, número, tipos, habilidades y estadísticas.
- PokéStyle: presenta un catálogo de productos de ropa.
- PokéChef: permite buscar recetas, consultar sus ingredientes e instrucciones y descubrir recetas aleatorias.


## Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el comando:

```bash
flutter pub get
```

4. Ejecutar la aplicación:

```bash
flutter run
```
